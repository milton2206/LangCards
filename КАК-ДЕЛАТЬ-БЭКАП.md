# Как делать бэкап LangCards

Бэкап делает копию базы Supabase — аккаунты, слова, языки, банк заданий.
На Free-тарифе Supabase автоматических бэкапов НЕТ, поэтому этот скрипт —
единственная страховка. Озвучка (mp3) сюда не входит: она общий кэш,
при потере пересоздаётся.

---

## Когда делать бэкап

ВСЕГДА перед:
- выполнением `schema.sql` в Supabase (любая миграция, любое изменение структуры базы)
- первым тестом удаления аккаунта
- любым массовым изменением данных

Порядок железный: сначала бэкап → потом опасное действие. Не наоборот.

---

## Как сделать бэкап

1. Открыть PowerShell и перейти в папку проекта:

   ```
   cd D:\Projects\lang-cards
   ```

2. Запустить бэкап:

   ```
   npm run backup
   ```

   В конце появится сообщение вроде «228 строк сохранено».
   Файл создастся в папке `backups/` с датой в имени:
   `langcards-backup-2026-07-27_15-30.json`

3. Проверить, что файл создался:

   ```
   dir backups
   ```

4. (Только в первый раз) открыть файл в блокноте или VS Code и убедиться
   глазами, что там реально данные — аккаунты, слова. Дальше можно не открывать.

---

## Как восстановиться, если что-то сломалось

1. Сначала сухой прогон — показывает, что восстановится, НИЧЕГО не меняет:

   ```
   npm run restore -- backups/langcards-backup-2026-07-27_15-30.json
   ```

   (подставить имя своего файла)

2. Убедился, что файл правильный — применить по-настоящему:

   ```
   npm run restore -- backups/langcards-backup-2026-07-27_15-30.json --apply
   ```

   Восстановление аддитивное: добавляет и чинит строки, ничего лишнего
   не стирает. То есть испорченные миграцией данные починит, а новых
   пользователей, появившихся после бэкапа, не тронет.

---

## Важно

- Файлы бэкапа лежат ТОЛЬКО на твоём компьютере (в git не уходят —
  там email'ы людей, это персональные данные).
- Значит если полетит компьютер — копий не станет. Перед крупными
  миграциями скопируй свежий файл ещё куда-нибудь: флешка, облачная папка.
- Папка `backups/` уже в `.gitignore` — не убирай её оттуда.

---

## Короткая шпаргалка

```
cd D:\Projects\lang-cards          # перейти в проект
npm run backup                     # сделать бэкап
dir backups                        # проверить, что файл создался
```

Восстановление (если понадобится):
```
npm run restore -- backups/ИМЯ-ФАЙЛА.json           # предпросмотр
npm run restore -- backups/ИМЯ-ФАЙЛА.json --apply    # применить
```
